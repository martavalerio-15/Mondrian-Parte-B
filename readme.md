# MartaValério_ParteBMondrian

Para a Parte B, escolhi o alterar o retângulo vermelho. Em cada frame, a sua largura varia entre 360 e 370 px e a sua altura entre 310 e 320 px (através do uso do random), por isso o vermelho acaba por tapar por momentos a linha vertical e a linha horizontal que o delimitam. Usei uma frameRate(7) para que esta expansão do retângulo vermelho seja mais lenta. O desvio é de apenas 10 px, para o quadro continuar reconhecível.
